Cernis benchmark — consent

This browser session will be recorded to build a public dataset for detecting AI-driven web agents. Recording is anonymous and your participation is voluntary.

What is collected

  • Behavioural / timing features per HTTP request (which page, status code, bytes, how long since the previous click, request rate).
  • Page-level beacons sent by the test app (mouse movement, scroll, time to first interaction). Used to tell humans apart from automated agents.
  • A coarse browser bucket (e.g. chrome-desktop) — derived once from your User-Agent and immediately discarded.

What is NOT collected

  • Your IP address.
  • Your raw User-Agent string.
  • Request bodies (anything you type into a form).
  • Cookies, authorization headers, or any credentials.
  • Any identifying information whatsoever.

Purpose

The recorded sessions become part of a benchmark used to train and evaluate detectors for autonomous LLM-driven browser agents. The benchmark may be released publicly.

How to use the test app after you accept

You'll be redirected to DVWA (a deliberately-vulnerable test web app). It will ask you to log in. Use these credentials:

username: admin    password: password

Then browse a few pages naturally — there's nothing specific you have to do. When you're finished, just close the tab.
